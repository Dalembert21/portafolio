# Personal Portfolio

## Description

Personal portfolio website developed to showcase my professional profile, technical skills, projects, and contact information. The website includes information about my experience as a Full-Stack Developer, featured projects, technologies, and soft skills.

## Features

* Modern and intuitive user interface.
* Responsive design for desktop, tablet, and mobile devices.
* Bilingual support (English and Spanish).
* Downloadable CV.
* Featured projects section.
* Technologies and skills showcase.
* Contact section.

## Technologies Used

* React
* JavaScript
* CSS3


## Responsive Design

The application is fully responsive and optimized for different screen sizes and devices.

## Deployment

Deployed on Vercel for fast and reliable access.
